# Glossary (my own renderings)
Characters: Kevin, Mark, Jim, George, David, Alyssa, Yoko, Cindy. AIPC (computer partner). Raccoon City.
Terms: main data, save/load, File(s), SP item, infection (gauge/rate), Appeal, Ad-lib, Order (使用指示), Ask (要求), Give (差し出し).
Scenarios: the official English release's names (players know them): 初心 Training, 咆哮 Wild Things, 異界 Underbelly,
記憶 Flashback, 死守 Desperate Times, 突破 End of the Road, 殲滅 Elimination (1-3), 対峙 Showdown (1-3).
Places follow the Japanese name literally (Apple Inn, Elephant restaurant, Jungle dome, Annex, Main building...).
Voice: terse; Kevin/Mark/David gruff, Jim casual, George measured, Alyssa sharp, Yoko timid, Cindy warm.
Devices (the user's rule: the text is read once, so it can't follow the device): no PlayStation, memory card or HDD. Memory
card -> save data / save file / save slot N; the HDD -> the drive, INSTALL; "press the circle button" -> the action's name:
Confirm and Back/Cancel in menus; in play Action (circle), Cancel (cross), Ad-lib (square), Map (triangle), Ready (R1), Ready
Forward (R2), Switch Target (L1), Appeal Shift (L2), Appeal (right stick), Status (START). Button symbols only where the text
is about the gamepad itself (the controls lists).
