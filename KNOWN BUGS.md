# Known bugs

Biohazard Outbreak for Mac – fan project by HAB3X. Found something else? [Report a bug](https://github.com/HAB3X/Biohazard-Outbreak-Mac/issues/new/choose).

**Online**
1. Starting a scenario from an online room isn't confirmed working yet. Login, the lobby and joining rooms work.
2. The mouse in the lobby after logging in is untested and may not work everywhere.

**Mods**
3. Character mods show in the launcher but the games don't load them yet.
4. Some HD texture packs show pale patches on trees (File 2's zoo).
5. File 2, first person: a pale rectangle at the left of the view in the zoo's first street.

**Menus**
6. File 2's collection: clicking the tabs picks the wrong one.
7. File 1's difficulty menu only moves one step with the keys.
8. The map can't be scrolled or zoomed with the mouse.

**Other**
9. The first time you open the app, macOS blocks it. Go to System Settings › Privacy & Security › Open Anyway.
