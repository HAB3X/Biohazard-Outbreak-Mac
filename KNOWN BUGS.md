# Known bugs

Found something else? [Report it](https://github.com/HAB3X/Biohazard-Outbreak-Mac/issues/new/choose).

**Online**
1. Starting a scenario from an online room isn't confirmed yet.
2. The mouse in the online lobby may not work everywhere.

**Mods**
3. Character models bigger than the costume they replace are skipped.
4. Some HD texture packs show pale patches on trees in File 2's zoo.
5. File 2, first person: a pale rectangle in the road of the zoo's first street (and pale patches on trees). The game's own VU1 code pins vertices of the big ground triangles near the camera to a fixed screen range, which bends them and leaves a gap; the software renderer shows it too. Not fixed.

**Other**
6. The first time, macOS blocks the app: System Settings › Privacy & Security › Open Anyway.
